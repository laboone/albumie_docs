# 高性能AIによる写真の自動選択
高性能AIを使用して、アルバムに最適な写真を自動で選ぶことができます。  
この機能を利用することでアルバムに入れる写真を効率的に選べます。

:::info
この機能はアップロードしている写真の枚数によって料金がかかる有料のオプション機能です。  
すべての写真をアップロードしてからこの機能をご利用ください。  
支払い後に写真を追加でアップロードすると、この機能は使用できなくなります。  
使用するには再度すべての写真枚数分の料金がかかりますのでご注意ください。
:::

## 料金の支払い
1. アルバム一覧ページからアルバムをクリックします。
1. ページ右上の「写真の自動追加」ボタンをクリックし、表示される写真の自動追加ページで「高性能なAIを使用して写真を選ぶ」をチェックします。
1. [コレクション](/advanced/create-collection)に保存している写真の枚数によって料金が表示されます。「申し込む」ボタンをクリックすると料金支払いページが表示されますので支払い情報を入力してお支払いを完了してください。

支払いが完了すると、写真の解析が実行され、完了時にはメールでお知らせが届きます。
解析には最大1日かかる場合があります。  
解析が終わると高性能AIによる写真の自動選択ができるようになります。

コレクション単位での支払いとなりますので、別のコレクションでもこの機能を使用する場合は、そのコレクションに保存している写真枚数分のお支払いが必要です。

## 写真の自動選択
解析が完了すると、写真の自動追加ページで「高性能AIによる写真の選び方」を設定できるようになります。  
写真の選び方は以下の2通りです。

- よい写真を優先
  - その人物の写真の中で似た写真を避けながら、AIの評価が高い写真を選びます
- いろいろなシーンを優先
  - 他の人物の写真も含めて似た写真を避けながら、いろいろなシーンが入る写真を選びます

:::info
連写のようにほぼ同じ写真が何枚もアルバムに入らないように、重複した写真は自動選択の候補から除外されます。  
すでにアルバムに追加されている写真と重複する写真も除外されます。  
重複した写真しか候補に残らない場合、その人物の写真選びはそこで終了します。  
似た写真で枚数を埋めることはしないため、指定した枚数に届かないアルバムになることがあります。
:::
